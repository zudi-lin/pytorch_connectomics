- [major] The execution order still violates the GT firewall. `stage0_reproduce.py` reads the test skeletons before Stage 2 freezes assignments, and Verification step 7 explicitly runs it “before any policy is resolved.” The task permits evaluator access only after assignment manifests are immutable. Additionally, Stage 3 refers to an assignment SHA in a “pre-evaluation report,” but the declared sibling JSON records only `proposal_sha256`; the artifact that freezes and attests the assignment bytes is undefined.

- [major] Selector behavior still requires invented rules. `contact_area` has no acceptance gate or clear-winner definition; floor-only policies do not state how exact ties satisfy the clear-winner requirement; singleton candidates have no defined runner-up score or margin; and mixed clean/quarantined candidate sets do not specify whether quarantined anchors participate in ranking. The sort direction for `anchor_id` is also unstated. The `3e5` anchor-floor sensitivity variant is not encoded in output names, so its manifests and assignments would collide with the primary variant.

Principal-axis construction is unspecified, and `tangent_cos >= 0` is not invariant to the arbitrary sign of an unoriented principal axis.

- [major] The raw affinity channel contract is clearer, but the verification truth table remains insufficiently source-indexed. “Shifted by `-e`” does not specify whether output index `v` reads input `v-e` or `v+e`, nor the valid slicing domain and boundary treatment. Stage 1 records only fragment-anchor edges, while complete-graph depth-2 resolution requires fragment-fragment adjacency and its evidence; Stage 0 retains only RAG degree. The “precision gate” has no numeric definition, and triggering a new Stage 2 run from Stage 3’s GT-measured precision would feed test evaluation back into selection.

A candidate edge table containing only actual fragment-anchor edges cannot enumerate zero-contact fragments while Stage 2 reads “the candidate table only.” With missing evidence first in precedence, `no_anchor_contact` may also be unreachable unless missingness is further defined. The new `2000 nm` and `0.3` numbers therefore relabel rather than fully resolve the earlier reproducibility issue.

- [major] The evaluator-only ceilings lack composition rules. For oracle backbones, the plan does not define whether frozen assignments are applied before or after oracle joins or how joined anchor aliases affect ownership. For oracle-clean anchors, filtering already-frozen assignments versus removing contaminated anchors and re-ranking clean candidates produces different ceilings. The coder would have to invent both contracts.
